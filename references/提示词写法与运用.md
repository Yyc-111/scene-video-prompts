# 提示词写法与运用

版本1.12。用于把卡片变为本次正文、精简初稿或修订具体问题；只读与当前问题相关的部分。此处不增加每镜必填字段，总规则仍见 [内容设计与复核](内容设计与复核.md)、[编排与检查](编排与检查.md)。下列为原创文字演练，未实测；短句只是局部写法，完整方案见 [案例索引](知识库/08_完整案例/00_案例索引.md)。

## 1. 从起点写到可见终态

先看实际首帧；没有实际图时只能依据明确标注的规划。一次主行为可以包含必要阶段，不按动词数量机械拆镜。

|当前条件|写法与取舍|
|---|---|
|胸前已持杯，饮后继续持杯|“杯口送至唇边轻抿；杯口离唇后，杯子降至胸前，手继续握持并停留。”避免“回原处”歧义|
|杯在桌面，手未接触|先核对可达距离、杯柄方向、哪只手空闲；写清取杯再举杯。时间不足时缩小行为目标，或在双图策划时设计已持杯起点|
|任务要求把杯放桌上|明确可达落点，杯底接触桌面后再松手；不能由胸前悬空握持直接跳成桌面杯|
|已打开书，目标是安静阅读|保持扶书和阅读姿态即可，不自动加翻页；用户要求翻页时再检查手指接触页角、翻动与落页的连贯性|

可见反馈只选与行为有关的一项。例如放杯可由杯底接触桌面体现完成，不必另加水波、热气、笑容。接触部位若不在画面内，先决定是否需要调整景别，不能仅靠细节词弥补不可见。

## 2. 安排观众看清什么

人物视线是人物看哪里；观众注意力是画面优先让人读到什么；移焦是改变焦平面。三者可以配合，但不互相替代。

|任务|正文写法|避免|
|---|---|---|
|看清一次轻抿|“取景保留脸、握杯手与杯口，饮用过程手与杯口保持可辨认。”|为了浅景深让手和杯全程模糊|
|看完整发长|“取景从头顶至发尾以下，转动后的发尾仍留在画面内。”|只有脸周特写却要求看到全长|
|读书后的抬眼|先让书和扶书关系可读，再以抬眼把注意力引向脸部|默认增加一次移焦或推镜|

不要求所有背景清晰。保留当前任务的必要信息，其余可适度弱化；背景虚化、人物遮挡和移动后的裁切要一起判断。

## 3. 给运镜一个起停理由

“缓缓推近”还应落到本次起始取景、启动时机及结束范围。示例：人物目光转向窗外后，相机开始轻缓推近，结束时仍保留握杯手与杯子。若手杯会被裁掉，就减小推进幅度或改固定观察。

固定机位也可以表达安静观察。跟随时说明人物与相机的相对速度；人物继续走到片尾不必强行停步。起停依据是本镜任务，不是“每个情绪高点必须停车”等通用公式。时码属于创作安排，不承诺生成器逐秒执行。

## 4. 情绪意图与少量可见表现

保留帮助理解情境的一句意图，再用少量可见表现落实。不能把心理词当作已实现的表演，也不必删除所有情绪背景。

|情境|局部写法|适用条件|
|---|---|---|
|安静看景|“目光停在窗外同一处，眉眼舒展，嘴部自然放松。”|存在合理观察方向，不杜撰画外目标细节|
|认真听人说话|“目光朝向画外同伴，听到一个完整片段后轻点一下头。”|已明确交流情境；不是自行增加同伴或音轨的许可|
|饮后休息|“杯口离唇后嘴部恢复自然状态，肩部轻微放松。”|嘴部先完成饮用；肩部变化属于整体动作编排，不塞入微表情卡职责|

选择符合情境的一种，不叠加整张表。人物可以一直保持舒展，不强制每镜从平静到浅笑再收回。眨眼、笑意、下巴变化只有可读且不冲突时才写。

## 5. 精简时保住任务条件

优先删除空泛质量形容、重复锚定、无依据环境事件及重复禁令，再合并重复句。输入图已确定的外观可用简短锚定保留；不能删除用户强调的肤质、实际动作条件或镜间必要连续性。不规定跨平台英语字数预算、中文字符上限或唯一槽位顺序。

**假设输入：**已确认的窗边胸前持杯首帧，用户指定8秒，只要喝一口后继续持杯；未见气流或热气。以下示例不替代真实读图。

**待精简稿：**

> 高级电影质感，精致自然、非常真实、画面优美。保持人物身份、人物还是原来的人、发型不变、发型保持原样、衣服还是原衣服、窗边还是原窗边。镜头固定，摄影机不移动。人物轻轻举杯，喝一小口，把杯放回原处。热气升腾，头发微动，窗帘飘动。自然肤色，脸和嘴唇没有明显亮斑。不要换人，不要换脸，不要换衣服，不要字幕。

**修订稿：**

> 保持首帧人物身份、发型、服装与窗边空间。固定机位，保留脸、握杯手和杯口的可见范围。人物将胸前的杯子举至唇边轻抿一口，杯口离唇后降至胸前并继续握持，停留至8秒结束。沿用首帧柔和窗光与自然肤色，脸和嘴唇没有明显亮斑。全程一镜，不出现字幕。

删除理由：质量形容不能替代具体要求；身份和固定机位各写一次；热气、风动无输入依据；把“原处”改为胸前并明确继续握持。保留8秒、动作终态、可见范围和用户肤质偏好。此稿仅用于这组假设条件，不是固定头尾的新替代模板。

## 6. 首帧修订写清改变与保留

假设实际图只有嘴唇亮斑不符：

> 仅减弱嘴唇表面的明显镜面亮斑，保留原有唇色、唇形和柔和体积明暗。人物身份、姿态、握杯位置、构图及窗户光源位置保持原样。

假设手悬空、没有握住杯柄：应联动手腕、手指和杯柄接触关系。它们属于同一结构问题，不为“一次只改一项”留下不成立的姿态。若修改主动作，则重新检查受影响的首帧、取景、受光和时间；保留项不能阻止必要修正。

实际图与规划不一致时，不把规划文字当作实际已存在。图片修订词只是文字交付，不自动调用生成服务。

## 7. 环境与材质按因果选择

窗外雨滴沿玻璃滑动，不代表室内头发也要吹动。杯子反射窗光不代表皮肤和嘴唇需要同样的亮斑。材质细节应来自参考或明确的设计，不用毛孔、老化、汗水、灰尘等清单自动增添真实感。

先判断有无动态依据，再选能在本景别中读出的尺度。没有合适环境运动可以不写；人物呼吸也不必被夸大成明显胸肩起伏。光源固定于场景，人物转向或相机换位后的受光与画面左右方向按 [光源与受光判断](光源与受光判断.md) 推导。

## 8. 从失败现象定位修订范围

|现象或用户报告|先核对|对应修订|
|---|---|---|
|杯子穿脸|实际首帧杯口、握持、路径及提交词|起点错误先修首帧；路径不清再改视频词，不能只加“不要穿模”|
|成片像静止照片|是否有可见变化目标；是否把姿态和所有物体写成完全不变|移除过度冻结，保留符合用户目的的一项行为；静谧任务不强加喝茶|
|手杯看不清|实际景别、遮挡、景深与运镜后的裁切|保证关键阶段可见，不自动换成极近景|
|浅笑显得机械|是否与抿饮冲突；是否无触发重复起落|删除冲突笑容或改为保持舒展，先保住主动作|
|换机位后脸的明暗反了|场景光源、人物朝向与新机位|纠正受光推导，不用新增补光或整体压暗掩盖|

依据不足时明确只根据用户描述推测，不冒充看过视频。每次修订保留原词与问题记录，新方案仍标未复测。接入 [验证与反馈](验证与反馈.md)，不另设一套评分。

## 9. 跨层失败定位（提示词只能治提示词这层）

提示词层能解决的是**表达层**：要不要保留身份、要不要把动作阶段写清楚、要不要给机位和受光说明。表达层修得再好，也解不开下表里更深层的问题。**每次返工前，先用这张表确认问题不在其它层。**

|现象|更可能的根因|提示词能否解决|该去改哪一层|
|---|---|---|---|
|手臂变形、腿过长、多指|源图本身是 AI 图，无 3D 约束；运动放大形变|否|改源图（真人拍摄 / ControlNet 骨架 / HandRefiner）|
|滑行感、不像真走|首帧高频细节触发 I2V 模型运动抑制；或单帧让模型自猜动作|否|首帧低通（[首帧体检](首帧体检.md)）；改用首尾帧或参考视频驱动|
|脸崩、身份漂移|无身份锚点；运镜把人脸推出画面后回来认不出|部分（明确写回位角度与受光）|加 IP-Adapter / PuLID 锚身份；减少大幅度离脸运镜|
|光线与场景不符|环境动态写成雨，室内却吹头发；室外窗光却当棚拍光|部分（写清因果）|按 [光源与受光判断](光源与受光判断.md) 推导受光；不要单独靠提示词修饰|
|杯子穿模|起点错误（手未真正握住）或路径写错|否（是规划问题）|改首帧 + 双图策划，不要只加"不要穿模"|
|成片 8K 感太强、塑料皮肤|提示词用了反向词（`8K / hyper-detailed / masterpiece / ultra-realistic`）把模型推向 CGI|是（最高优先级）|删反向词、加可见皮肤纹理与方向光|
|动作重复、机械感|同一动词写两遍；或者把动画意图当结果|部分|精简动词、给分阶段；长动作分段，不要在一句话里堆步骤|
|剪辑后单镜过长|把多镜合并成一句；时长规划没分给单镜|是|回到 [多镜头规划](多镜头规划.md) 重新分镜，不要延长单镜时长|
|同一卡多次都失败|提示词之外的因素：模型版本、首帧本身、云端 API 不可控|否|换模型；改源图；连跑 3 次取优，不要在提示词上反复微调|

**判定流程：**
1. 把现象放到上表，看"提示词能否解决"那一列。
2. 标"否"的项目，再多改几版提示词也不会变好。直接去对应层处理。
3. 标"部分"的项目，写提示词 + 改那一层一起做，单做一边都缺一半。
4. 标"是"的项目，先按本模块 1—8 节改表达方式。
5. 同样现象连跑 3 次都不变，确认不是运气，再下结论。

**反例：**遇到"手臂穿模"只在提示词里加"不要穿模、不要畸形"——列于表中是"否"项，加多少禁令都不会让模型真的回避。它属于源图与生成机制层，先修源图或换参考方式。
