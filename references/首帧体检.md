# 首帧体检

版本1.13。本模块在**写视频词之前**检查首帧本身，处理 [生成链路与风险分层](生成链路与风险分层.md) 的 L1 与 L2。

本库此前的模块都在 L4（提示词写法）。本模块是唯一面向素材与预处理的一层。全部阈值为本项目经验区间，来自本轮项目诊断记录与公开研究结论，**未做对照生成实测**，不作为平台规则或通过标准。

## 为什么要在写词之前检查

图生视频模型的运动幅度会受到参考图高频细节的压制：参考图细节越锐、越"满"，模型越倾向于锁死静态细节，把大尺度运动压掉，成片表现为动作接近滑行或接近静止。这一现象在公开研究中有记述（见 [来源与改编](来源与改编.md)），本文只据其结论设计检查项，不把它当作任何具体平台的可调参数。

因此：**在写词之前先判断首帧是否需要预处理**，比写完词再反复修改更省事。

## 两项判读指标

|指标|含义|偏高意味着|
|---|---|---|
|锐度|灰度拉普拉斯算子均值，反映微细节强度|细节过密，易触发运动压缩|
|频谱斜率 β|径向平均功率谱的 log-log 拟合斜率，反映高频是否被异常增强|β 越接近 −1.5，说明高频被后期或采样放大过|

自然拍摄的照片，β 通常在 **−2.0 至 −2.4** 之间。

### 本项目经验区间

|锐度|β|判读|建议|
|---|---|---|---|
|> 18|> −1.8|高频偏强|先低通再做视频词|
|9—18|−2.0 至 −1.8|中等|可直接使用；成片偏木时再低通一次|
|< 9|< −2.0|接近实拍|不需低通|

以上区间来自本轮项目对六张参考图的测量，是本项目的参考刻度，不是通用标准。不同题材的合理值不同（例如纯环境空镜本就允许更多细节）。

**注意**：本项检查与 [自然真实感检查](自然真实感检查.md) 的"保留参考已有皮肤纹理"不冲突。后者要求不主动添加雀斑、毛孔等瑕疵；本模块处理的是**已经过锐的整体细节密度**，两者方向相反，不要混用。

## 低通预处理

两种做法，取其一：

|做法|参数|说明|
|---|---|---|
|降采样回升（推荐）|缩放到 50% 再插值回原尺寸|最接近研究中的实现方式，保留构图与色彩|
|高斯模糊|sigma 约 1.0|更平滑，但对边缘的处理不如上一种自然|

**这是有代价的交换**：低通越强，运动幅度余地越大，但细节锐度损失越多。

- 第一次做用 **50%**，不够再往下走到 35%。
- 不要一步做到 25%，也不要对人物面部单独低通（会造成脸与身体锐度不一致）。
- 低通属于**素材预处理**，不写进提示词；提示词仍按 [自然真实感检查](自然真实感检查.md) 描述材质。

## 构图风险规则

除锐度外，以下三条直接决定 L3 的压力大小。**同时满足三条时风险最高**，建议至少去掉一条：

1. **全身景别**（头顶到双脚同时可见）
2. **大幅度肢体伸展**（张臂、举手过头、抬腿）
3. **单张静态参考 + 单镜超过 2.5 秒**

处理方式：

- 去掉第 1 条：改为中景或中近景，见 [镜-A1](../知识库/01_镜头/镜-A1_人物与环境.md)、[镜-D2](../知识库/01_镜头/镜-D2_坐姿与桌面.md)。
- 去掉第 2 条：把高风险肢体收进画面之外，或改为不需要伸展的等价动作。手部尤其如此——**手不在画面里，是最省事也最有效的规避方式**（例如双手插袋、扶着物件）。
- 去掉第 3 条：缩短单镜，或改用首尾两帧（见 [双图首帧策划](双图首帧策划.md) 的终态设计），让模型不必从头推断。

## 分辨率与放大

- 素材分辨率建议**直接生成到目标输出尺寸**，不要先小后大。多次重采样会推高 β，等于自己制造 L2 的触发条件。
- 已有多余放大的素材：体检时按上表判读，必要时做低通。

## 检查表

写视频词之前逐条过：

- [ ] 锐度与 β 已测量，按区间判读
- [ ] 判为"高频偏强"的素材已做低通，并记录所用参数
- [ ] 全身、肢体伸展、长镜头三项未同时成立
- [ ] 手部已尽量移出画面，或已确认手部为必需信息
- [ ] 素材分辨率与目标输出尺寸一致
- [ ] 首帧的缺陷（若无法修图）已明确告知，不用"沿用首帧"把错误再次锁定

以上任一项未过而仍直接写词，应在交付时说明该风险，并按 [生成链路与风险分层](生成链路与风险分层.md) 记录为 L1／L2 未解决项，不计入提示词层的问题。

## 与其它模块的关系

- 光源、受光与人物朝向：先做 [光源与受光判断](光源与受光判断.md)，本模块不改受光设计。
- 材质与用户偏好：本模块不修改 [自然真实感检查](自然真实感检查.md) 的材质要求。
- 首帧缺陷修复属于修图，不属本库输出范围；本库只交付判断与文字。
