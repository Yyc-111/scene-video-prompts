# 镜-D3 环境中的人物

- 编号：镜-D3
- 名称：环境中的人物
- 子类：01_镜头
- 版本：1.7
- 依据：原创场景化整理；方法参考见 [镜头来源审阅](../../镜头来源审阅.md)，不是官方模型规则。
- 适用场景/拍摄目的：呈现人物如何处于场景。
- 首帧要求：环境有足够空间，主体不被遮挡。
- 起始构图：人物全身与足够环境，主体位置依场景确定。
- 起始机位：沿场景现有透视观察，优先平稳视角。
- 人物路径：原位观察或小范围活动。
- 摄像机路径/结束画面：环境和人物同时保留。最终方案须结合图片明确方向和终点；镜头类卡的相机路径由选用运镜卡补足。
- 速度关系/时机：服从用户指定时长，按拍摄目的确定是否等距；无动作时不杜撰运动。
- 时长适配：只在用户总时长内安排开始、持续和结束，不自行延长或强行完成复杂路径。
- 推荐搭配：运-A1、运-E1。
- 禁搭配及原因：
  - 必须禁止：无额外要求。
  - 条件限制：人物脸太小时细微眼睑变化不可作为验收目标。
  - 风格建议：优先人物与环境关系。
- 实测备注：未实测；实际首帧、版本、秒数、正文快照和结果待录入。

## 提示词原文

以人物全身和周围环境共同入画，沿人物视线或活动方向保留空间，让场景关系清楚可见。
