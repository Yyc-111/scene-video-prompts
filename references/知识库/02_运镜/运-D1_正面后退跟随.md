# 运-D1 正面后退跟随

- 编号：运-D1
- 名称：正面后退跟随
- 子类：02_运镜
- 版本：1.7
- 依据：原创场景化整理；方法参考见 [镜头来源审阅](../../镜头来源审阅.md)，不是官方模型规则。
- 适用场景/拍摄目的：陪伴式记录行走。
- 首帧要求：人物与相机路径均有空间。
- 起始构图：完整全身或所需范围，主体大小基本不变。
- 起始机位：人物正前方，镜头朝向人物。
- 人物路径：人物向前行走。
- 摄像机路径/结束画面：相机在前方后退，维持相近距离。最终方案须结合图片明确方向和终点；镜头类卡的相机路径由选用运镜卡补足。
- 速度关系/时机：服从用户指定时长，按拍摄目的确定是否等距；无动作时不杜撰运动。
- 时长适配：只在用户总时长内安排开始、持续和结束，不自行延长或强行完成复杂路径。
- 推荐搭配：镜-D1、动-D1。
- 禁搭配及原因：
  - 必须禁止：等距等焦距跟随同时要求人物持续大幅放大；相机固定又后退。
  - 条件限制：后退路径可通行，人物朝向明确。
  - 风格建议：保持稳定距离。
- 实测备注：未实测；实际首帧、版本、秒数、正文快照和结果待录入。

## 提示词原文

镜头位于人物正前方，随人物前行平稳后退，保持相近拍摄距离和原有取景范围。
