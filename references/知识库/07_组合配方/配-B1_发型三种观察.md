# 配-B1 发型三种观察

版本1.7；原创配方，未视频实测。
镜1：镜-C1 + 运-A1 + 微-A1 + 光-C1，主任务为完整发长的持续观察。
镜2：镜-B1 + 运-A1 + 动-B1 + 微-A1 + 光-C1。
镜3：镜-C1 + 运-A1 + 微-A1 + 光-C1，主任务为已提供参考支持的侧部层次观察。
适用：用户需要全长、脸周和侧面三种信息，参考与场景支持且时长充足。无必要时缩为更少镜数，不默认三镜或15秒。
每镜均选择头尾并按对应首帧编排；持续观察含人物自然微动，不叠加无动机动作。完整假设输入快照见 [演练003](../08_完整案例/演练-003_室内发型三镜.md)。
