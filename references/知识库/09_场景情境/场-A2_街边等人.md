# 场-A2 街边等人

- 编号：场-A2
- 子类：09_场景情境
- 名称：街边等人
- 版本：1.7
- 依据：原创设计/经验推断；方法出处及支持范围见 [来源说明](../../来源与改编.md)，无该组合的官方或实测结论。
- 适用场景：户外日常
- 首帧要求：已站在步道边，朝向可观察街道的一侧
- 时长适配：服从用户指定秒数；先保留主动作，缩短时取消次要准备或回落，留出自然停留，不强制完整动作链。
- 推荐搭配：镜-A1 + 运-A1 + 动-B1 + 微-A1 + 光-A1
- 禁搭配及原因：
  - 必须禁止：不得安排穿过实体物件的姿态或相互矛盾的同时动作。
  - 条件限制：街边有等待与观察空间。
  - 风格建议：不默认添手机或让新同伴入画。
- 实测备注：未实测；平台/版本、图片、秒数、结果和反馈待实际使用后填写。
- 生活动机：等待同伴时留意来人方向。
- 起点/终点：从当前视线转向一个方向并停留。
- 场景专属条件：需可见步道与可观察方向的街道空间；不新增手机、同伴或车辆入画。

- 场景触发与区别：留意预期来人的方向，未安排实际有人到达。

## 提示词原文

保持首帧的街边等人环境，围绕“等待同伴时留意来人方向”组织一个连续生活片刻。
