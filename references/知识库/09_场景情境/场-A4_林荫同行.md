# 场-A4 林荫同行

- 编号：场-A4
- 子类：09_场景情境
- 名称：林荫同行
- 版本：1.7
- 依据：原创设计/经验推断；方法出处及支持范围见 [来源说明](../../来源与改编.md)，无该组合的官方或实测结论。
- 适用场景：户外日常
- 首帧要求：人物已站立或行走，通道与身体活动空间清楚
- 时长适配：服从用户指定秒数；先保留主动作，缩短时取消次要准备或回落，留出自然停留，不强制完整动作链。
- 推荐搭配：镜-A1 + 运-C1 + 动-D1 + 微-A1 + 光-A1
- 禁搭配及原因：
  - 必须禁止：不得安排穿过实体物件的姿态或相互矛盾的同时动作。
  - 条件限制：站立／行走首帧和可通行空间，推荐运-C1。
  - 风格建议：同行散步，不自动加回眸。
- 实测备注：未实测；平台/版本、图片、秒数、结果和反馈待实际使用后填写。
- 生活动机：和拍摄者同路散步。
- 起点/终点：沿现有通道自然走，保持方向。
- 场景专属条件：需有可通行通道与足够行走空间；首帧为站姿或行走，不用坐姿首帧。

- 场景触发与区别：沿通道与拍摄者同行，不另造交流事件。

## 提示词原文

保持首帧的林荫同行环境，围绕“和拍摄者同路散步”组织一个连续生活片刻。
