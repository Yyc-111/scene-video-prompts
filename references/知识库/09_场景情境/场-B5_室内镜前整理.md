# 场-B5 室内镜前整理

- 编号：场-B5
- 子类：09_场景情境
- 名称：室内镜前整理
- 版本：1.7
- 依据：原创设计/经验推断；方法出处及支持范围见 [来源说明](../../来源与改编.md)，无该组合的官方或实测结论。
- 适用场景：室内生活、发型展示
- 首帧要求：人物站在镜前，镜面可见，脚下站立与身体转动空间合理；脸周发型清楚
- 时长适配：服从用户指定秒数；先保留主动作，缩短时取消次要准备或回落，留出自然停留，不强制完整动作链。
- 生活动机：出门前在镜前确认整体状态。
- 起点/终点：开始于站立、轻侧对镜并可见面部的姿态，结束于小幅转向镜头附近；不安排整圈转身。坐姿则换用动-B1。
- 场景专属条件：需有可见镜面与站立空间；只有梳妆台时改选普通室内场景；不新增原图中没有的梳子、卷发棒等道具；镜中反射内容与实景一致，不虚构镜中不存在的造型。
- 推荐搭配：镜-B1 + 运-A1 + 动-F1 + 微-A1 + 光-C1
- 禁搭配及原因：
  - 必须禁止：不得安排穿过实体物件的姿态或相互矛盾的同时动作。
  - 条件限制：镜面、站姿与转动空间成立；坐姿用动-B1。
  - 风格建议：不插指梳发，不增加打招呼；镜子反射与真实姿态一致。
- 实测备注：未实测；平台/版本、图片、秒数、结果和反馈待实际使用后填写。

- 场景触发与区别：出门前在镜中确认状态；需判断机位会不会出现在反射中。

## 提示词原文

保持首帧的室内镜前环境，围绕“出门前在镜前确认整体状态”组织一个连续生活片刻。
