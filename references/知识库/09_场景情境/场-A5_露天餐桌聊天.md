# 场-A5 露天餐桌聊天

- 编号：场-A5
- 子类：09_场景情境
- 名称：露天餐桌聊天
- 版本：1.7
- 依据：原创设计/经验推断；方法出处及支持范围见 [来源说明](../../来源与改编.md)，无该组合的官方或实测结论。
- 适用场景：户外日常
- 首帧要求：坐在露天桌边，正看画外同伴
- 时长适配：服从用户指定秒数；先保留主动作，缩短时取消次要准备或回落，留出自然停留，不强制完整动作链。
- 推荐搭配：镜-A1 + 运-A1 + 动-C1 + 微-B1 + 光-A1
- 禁搭配及原因：
  - 必须禁止：不得安排穿过实体物件的姿态或相互矛盾的同时动作。
  - 条件限制：桌边坐姿和明确交流方向；桌面道具不一定归主角。
  - 风格建议：轻松聊天反应，不自动编台词或再拿物件。
- 实测备注：未实测；平台/版本、图片、秒数、结果和反馈待实际使用后填写。
- 生活动机：听到同伴有趣的话。
- 起点/终点：保持交流朝向，笑意升起后放松。
- 场景专属条件：需坐在桌边且视线朝向画外同伴；不新增人物、台词或第二个取物动作。

- 场景触发与区别：画外同伴讲到轻松有趣的一句；属于创作设定。

保持首帧的露天餐桌聊天环境，围绕“听到同伴有趣的话”组织一个连续生活片刻。
