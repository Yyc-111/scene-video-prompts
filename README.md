# scene-video-prompts

一个用于 AI 视频生成的**中文分镜提示词策划技能包**。给它人物参考图、场景参考图和指定秒数，它输出首帧合成方案与完整的中文视频提示词，并自主判断使用单镜还是多分镜。

> 本仓库只产出**提示词文字**，不承担视频生成、剪辑或前置换脸／换发型。

## 它能做什么

- **双图策划**：分别读取人物图（外观身份）与场景图（空间、光线、情境），先设计人物在该场景中的首帧位置、姿态、手部、视线和构图，再规划后续视频
- **自主判断单镜／多分镜**：不需要用户指定镜头形式
- **按编号组合**：56 张提示词卡片可按需组合，也支持按编号直接指定
- **逐项审查**：主体锚定、镜头景别、运镜、主动作、微表情、氛围光影、负面约束、时长，逐项给出落点

## 安装

复制到 Codex 的用户级技能目录即可：

```bash
# Windows
cp -r scene-video-prompts %USERPROFILE%\.codex\skills\

# macOS / Linux
cp -r scene-video-prompts ~/.codex/skills/
```

> 注意：备份目录**不要**放在 `~/.codex/skills/` 内，否则其中的 `SKILL.md` 会与正式技能重名，导致加载冲突。

## 使用方式

在 Codex 中提供人物参考图、场景参考图，并说明目标时长，技能会自动触发。例如：

> 用这张人物图和这张庭院场景图，做一个 10 秒的视频提示词

## 设计约定

这个技能包刻意保持保守，以下动作**不默认使用**：插指梳发、大幅甩头、快速大幅运镜、环绕运镜。这是本项目的设计约束，不宣称是平台禁令。

另外，环境动态（如叶片晃动、蒸汽升腾）仅在**原图有可见依据时**才写入，不为填满字段而杜撰。
